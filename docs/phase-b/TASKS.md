# Πίνακας εργασιών – Φάση Β (Ομάδα 12)

> **Αυτό είναι το αρχείο που δείχνει τι έχει γίνει και τι είναι ελεύθερο.** Το τι σημαίνει κάθε εργασία το εξηγεί το [PLANO-OMADAS.md](PLANO-OMADAS.md) (ενότητα 3, ίδιος κωδικός). Εκεί, κάτω από κάθε ενότητα, η λίστα **«Απαιτήσεις εκφώνησης»** λέει τι πρέπει να καλύπτει η εργασία. Μια εργασία πάει σε 👀 μόνο όταν τις καλύπτει όλες.

## Κανείς δεν έχει «δικές του» εργασίες

Οι εργασίες είναι χωρισμένες **ανά ενότητα της εκφώνησης**, όχι ανά άτομο. **Όποιος ξεκινά, παίρνει την επόμενη ελεύθερη (○)**. Κανείς δεν περιμένει κανέναν: κάθε εργασία τελειώνει μόνη της πάνω στο σχήμα, στα κοινά δεδομένα (`00_base.sql`) και στον σκελετό που είναι ήδη στο `main`. Οι λίγες εργασίες που θέλουν κάτι άλλο πρώτα το λένε στη στήλη «Χρειάζεται».

Ο πιο εύκολος τρόπος: γράφεις στο Claude σου **`start`** και δουλεύει μόνο του, εργασία μετά από εργασία, μέχρι να τελειώσει το usage. Γράφεις **`finish`** όταν θες να σταματήσει και να αφήσει τα πάντα έτοιμα για τον επόμενο. Οι εντολές εξηγούνται στο [`CLAUDE.md`](../../CLAUDE.md), ενότητα 0.

Κάθε εργασία είναι **ολόκληρη λειτουργία**: procedures + δοκιμές + η σελίδα PHP της + ό,τι μικρά δεδομένα χρειάζεται + ένα σύντομο `docs/phase-b/tasks/<ID>.md` με απλή εξήγηση. Έτσι όποιος την κάνει γράφει SQL, PHP και δεδομένα, όπως θέλει η εκφώνηση («όλα τα μέλη σε όλα τα στάδια»).

## Πώς ενημερώνεται αυτό το αρχείο (το κάνει το Claude)

1. **Παίρνεις** μια εργασία μόνο αν είναι **○**, δεν υπάρχει branch `task/<ID>` στο GitHub και δεν υπάρχει ανοιχτό PR με τίτλο `<ID>: …`. Φτιάχνεις branch `task/<ID>` από το `main`, βάζεις **✱**, στη στήλη «Πήρε» το όνομά σου και την ημερομηνία, commit, push και **Draft PR** `<ID>: <τίτλος>`. Το push του branch είναι η «κράτηση»: αν απορριφθεί επειδή το branch υπάρχει ήδη, την πήρε κάποιος άλλος την ίδια στιγμή, και πας στην επόμενη.
2. **Τελειώνεις**: στο ίδιο PR **👀** και «Ready for review».
3. **Σταματάς στη μέση** (`finish` ή τέλος usage): μένει **✱**, και στη «Σημείωση» γράφεις `Σταμάτησε: <τι μένει>`. Την ίδια εργασία τη συνεχίζει πρώτα αυτός που την πήρε. Αν περάσουν **24 ώρες** χωρίς νέο commit, μπορεί να τη συνεχίσει οποιοσδήποτε (γράφει και το όνομά του στο «Πήρε»).
4. **Μετά το merge**: **✓**.
5. **Κόλλησες**: **⛔** + μία λέξη στη «Σημείωση», και μήνυμα στο group. Μετά πας στην επόμενη ελεύθερη.
6. **Αλλάζει το πλάνο** (νέα ή κομμένη εργασία, αλλαγή απόφασης): μία γραμμή στο «Ιστορικό αλλαγών» στο τέλος.
7. Αλλάζεις μόνο τη γραμμή της εργασίας σου. Αν βγει conflict σε αυτό το αρχείο, κρατάς και τις δύο αλλαγές.

Καταστάσεις: **○** ελεύθερο · **✱** σε εξέλιξη · **👀** σε review · **✓** έγινε merge · **⛔** κολλημένο · **✂** κόπηκε

**Review**: κάθε PR το ελέγχει **ένα άλλο μέλος** από αυτό που το έφτιαξε (εντολή `review`). Κανένα PR δεν περιμένει συγκεκριμένο άτομο. **Merge**: ο Σωτήρης (το Claude του μόνο όταν ο Σωτήρης το ζητήσει ρητά), μετά από ✓ ενός reviewer, ή μόνος του αν περάσουν 24 ώρες χωρίς review.

**Στήλη «Πήρε»**: δεν είναι ανάθεση, είναι καταγραφή. Από αυτήν βγαίνει στο τέλος ο πίνακας συμβολής του εγχειριδίου, και ξέρει ο καθένας τι θα εξηγήσει στην εξέταση. Για να είναι η συμβολή ισομερής (εκφώνηση V), το `start` προτιμά, όταν έχεις ήδη κάνει 2 εργασίες, μια ελεύθερη εργασία δεδομένων, index ή κειμένου (ενότητες IV, V) αν δεν έχεις κάνει καμία.
